# FIMAS – Ceník a vyhledávač skladu

Interní ceník skladových položek FIMAS s.r.o. Data v `index.html` jsou zašifrovaná (AES-256-GCM); bez přihlášení nejsou čitelná.

## Aktualizace
1. Otevřít ceník, přihlásit se jako admin → **Správa dat**.
2. Nahrát nové CSV skladu a/nebo export e-shopu, případně upravit uživatele.
3. **Stáhnout HTML pro web** → v tomto repozitáři *Add file → Upload files* → nahrát stažený soubor přejmenovaný na `index.html` → *Commit changes*.

Web se obnoví do 1–2 minut.
