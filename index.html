4 Uložit verzi pro web

Stáhne jediný soubor HTML se zašifrovanými daty a aktuálním seznamem uživatelů – nahrajte ho na web místo starého. Při každém uložení se data šifrují novým klíčem, takže odebraný uživatel ztratí přístup.

Máte neuložené změny – platí až po stažení HTML a nahrání na web.
