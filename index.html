4 Publikovat na web

Stáhne jediný soubor HTML se zašifrovanými daty a aktuálním seznamem uživatelů – nahrajte ho na web místo starého. Při každém uložení se data šifrují novým klíčem, takže odebraný uživatel ztratí přístup.

Máte nepublikované změny – platí až po publikování na web.
Propojení s GitHubem

Token je uložen zašifrovaně v části pro adminy – čtenáři k němu nemají přístup. Vytvoříte ho na GitHubu: Settings → Developer settings → Fine-grained tokens, jen pro repozitář fimas-cenik, oprávnění Contents: Read and write.
